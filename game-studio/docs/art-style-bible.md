# 晶灵农场物语 · 美术规格书（v1）

> 目的：把「最早那批手绘贴纸」和「后来 AI 出的图」统一到同一套可执行的规格上。
> 本文件是出图、后处理、验收的唯一依据；改规格先改这里。

## 1. 整体语言

奶油手账 / 贴纸拼贴：**暖纸底 + 深棕描边 + 奶油 die-cut 边 + 淡纸纹**。
角色与道具是「贴纸」，场景地面与战斗背景是「手绘纸面」，两者靠同一套色温与纸纹连起来；背景不描边，这是有意的分层。

## 2. 色板

| 用途 | 值 |
| --- | --- |
| 描边 | `#5A4335`（唯一） |
| 奶油边（角色/作物/精灵/魔物） | `#FDF7EC`，92% 不透明 |
| 地面色边（贴地布景：谷仓/树/围栏/地块/草垛/水槽/石子/花/独轮车/木牌/工具） | `#F2ECDA` |
| 纸面 | `#FBF3E7` / `#FFFCF6` |
| 强调 | 莓红 `#D35F7B` / 森绿 `#7C9B64` / 黄油 `#E7B453` |
| 元素色 | 木 `#7C9B64`、火 `#C05248`、水 `#6E8FA8`、土 `#C9922F`、光 `#D98BA8` |

## 3. 画布与线宽

| 资产 | 画布 | 描边（该画布下） | die-cut 边厚 |
| --- | --- | --- | --- |
| 精灵 / 魔物 / 角色 / 道具 | 1024×1024（或等比长边 1024） | 4–5px | 最长边 1.2% |
| 作物 | 长边 900 | 3.5–4px | 最长边 1.2% |
| 战斗背景 | 1536×864（16:9） | 无描边 | 无 |

缩放后线宽按比例走：到 512 宽约 2px，到 128 宽约 0.5px（再小就别缩，直接给 128 的成品）。

## 4. 明暗与质感

- 明暗最多 **2 层**：主色 + 一层 10–15% 暗部；高光最多 1 处，用更亮的同色系而不是纯白。
- 纸纹：统一在**场景层**加（`PixelWorld` 的 `getGrain()`），素材本身不加噪点，避免和缩略图冲突。
- 禁止：投影、地面、文字、多主体、半透明外发光（后处理会把它削平，反而脏）。

## 5. 饱和度区间（归一目标）

| 组 | 目标饱和度（HSV 平均） |
| --- | --- |
| 作物 | 0.50 |
| 动物 | 0.30 |
| 道具（布景） | 0.33 |
| 精灵（幼体/成体/魔物/BOSS） | 0.42 |
| 主角 | 0.39（12 张换装统一定标） |

## 5.1 主角换装

主角是「两性别 × 六套服装」共 12 张独立立绘（`owner_<gender>_<look>.png`），不是一张图套滤镜：
亚麻（默认）/ 绣花（奶油）/ 星辉（深蓝礼装 + 斗篷）/ 雨衣（芥末黄）/ 祭典（和服·甚平）/ 冬装（毛衣 · 围巾）。
每套按 `linen / embroidery / star / rain / festival / winter` 命名，`data.ts` 的 `EQUIPS[].look` 决定穿哪套。服装 → look 的映射在 `data.ts` 的 `EQUIPS[].look`，
`ownerArt.ts` 用 glob 收图，缺图时退回旧立绘。伙伴 NPC 用对方性别的亚麻套，保证同屏画风一致。

## 6. 工具链与执行顺序

1. 出图（Codex image_gen / GPT）→ `farm-tale-src/incoming-art/`
2. `tools/import-art.py --batch <组>`：去白底、清碎片、裁边留白、缩放到目标尺寸（贴地布景把白边换地面色）
3. `tools/normalize-art.py`：**剥旧边 → 补统一 die-cut 边 → 描边色归一 → 分组饱和度归一**（原图备份在 `src/assets/sticker-pre-normalize/`）
4. `./rebuild.sh` → 内联成单文件 → `game_studio_build` / `game_studio_export`

`normalize-art.py` 的例外：

- `plot` 跳过（接入时已手工把边色并进土壤色，重复剥边会把土壤冲淡）；
- 早期手绘的「柔边」资产（`SOFT_HALO`：鸡/羊/牛/主角/干草/水槽/石子/花/独轮车/木牌/水壶/奶罐、旧作物 5 张、常用旧幼体）只做描边色与饱和度归一，**不重建 die-cut 边** —— 它们的浅色晕圈是画的一部分（羊毛、花瓣），硬收会切出描边碎片。

## 7. 验收

- 描边色抽样（取最暗 2% 像素均值）应落在 `#4E3A2C ~ #6A5040`；
- die-cut 边厚度目测一致（同尺寸图并排看边缘宽度）；
- 缩到 128px 时仍能认出主体，边线不断；
- 同屏截图（农场/战斗/图鉴）里没有单张图"跳出来"。
